# 06 Verification

**확정 · D-004, D-006, D-007** Verification은 실제 테스트·분석 실행 근거와 확인 범위를 기록한다. 정상 개발과 수동 복구에서 커밋 전에 검증한다.

**제안 · O-005** Claim에서 판정 기준을 도출하고 실행 결과를 대상 코드 스냅샷, 실행 방법, 입력과 환경에 연결한다. 통과, 실패, 판단 불충분, 차단을 구분하고 기존 근거가 변경된 범위에 유효하지 않으면 stale로 표시한다.

~~~mermaid
flowchart LR
  C["Claim과 판정 기준"] --> X["테스트 또는 정적 분석 실행"]
  X --> E["실행 Evidence와 범위 기록"]
  E --> R{"커밋 기준 충족?"}
  R -->|예| K["코드와 관련 Artifact 커밋"]
  R -->|아니오| F["실패 또는 미검증 범위 기록"]
~~~

위험도별 증거 요구량, 정적 분석이 충분한 경우, 실행 결과 재사용 조건과 커밋 차단 정책은 미결정이다.
