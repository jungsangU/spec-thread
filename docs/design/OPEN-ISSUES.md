## 1.0의 추가 확인 사항

| ID | 구분 | 내용 |
| --- | --- | --- |
| ST-O14 | 운영 확인 | 제품 Git 필수 검사 지정과 사용자 태그 Push 후 설계 Release 게시를 실제 저장소에서 확인한다. |
| ST-O15 | 과거 근거 미확인 | 접근이 확인되지 않은 이전 대화·첨부의 추가 결정과 원격의 기존 설계 태그 유무는 확인하지 못했다. 후속 자료가 제공되면 현재 정책과 대조한다. |
| ST-O16 | 결정 완료 · CLI 구현 · PoC | ST-19·ST-20. failed 종료와 새 UUID·이전 실패 참조, 수정 가능한 오류의 in_progress 유지, 필수 Gate 정의·적용 이력·증거·유효성·후속 단계 차단을 검증한다. |

ST-O3·ST-O5·ST-O16 및 필수 Gate의 정책 결정은 완료됐다. 직렬화와 CLI 계약은 각 주제 문서의 Core 0.3.0 절에 기록했다. 실제 에이전트 실행과 프로젝트별 검사는 PoC 과제다. 기존 ST-O4의 외부 변경 Sync 비교 기준·승인 바인딩, ST-O14의 운영 검증, ST-O15의 과거 근거 확인은 별도로 유지한다.

Core 0.3.0은 features.yaml의 분석·생명주기·스키마 계약, Work Item의 Gate 정의·실행·이력 및 입력 유효성 검사를 제공한다. 자동 결과 재사용은 제공하지 않으며 후속 작업에서 과거 PASS의 유효성을 평가한다. ST-O6의 추가 재사용 최적화와 ST-O4의 외부 변경 Sync 승인 바인딩은 별도 과제다.
